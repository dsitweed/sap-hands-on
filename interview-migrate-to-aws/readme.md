# 2. 業務内容

オンプレミスおよびAWS環境における、サーバ基盤の設計・構築・移行・運用を担当いただきます。

- 基盤サーバの設計・構築・運用
- Webシステム基盤のバージョンアップ、リプレイス、保守運用
- DNS／NTP基盤のバージョンアップ、リプレイス、保守運用
- PHPで開発されたスクラッチシステムのアプリケーション環境運用
- バックアップソフトウェアの導入・設定・運用
- Linuxサーバの保守運用
- 設計書、構成図、手順書などの作成・改善
- 障害・インシデント対応
- 利用ユーザーからの問い合わせ対応
